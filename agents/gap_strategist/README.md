# gap_strategist

갭 지형 지도를 읽고, 연구자의 데이터로 실제 채울 수 있는 연구 모형을 제안합니다.

## 역할

gap_synthesizer가 만든 `gap_landscape_*.md`를 읽어서:
- 각 갭 군집을 우리 변인으로 채울 수 있는지 판단 (Full / Partial / None)
- 검증 가능한 연구 모형 최대 4개 제안 (실제 변인코드 사용)
- 교차지연 가능 여부 자동 판단 (변인사전 §6 규칙 내장)
- 기존 투고 논문 경로 자동 제외 (부당대우→EE→WM)
- 최우선 추천 모형 1개 선정

## 입력 / 출력

```
입력: gap_landscape_*.md 파일들 (gap_synthesizer 출력)
출력: gap_strategy_YYYYMMDD_HHMMSS.md (SYNTHESIS_DIR에 저장)
```

### 출력 구조

```
## ⭐ 최우선 추천
가장 이론적 기여도·데이터 적합성·방법론 차별성이 높은 모형 추천

## 🗺️ 갭 커버리지
✅ Full   — 우리 변인으로 완전히 검증 가능
⚠️ Partial — 일부 변인 부재, 부분 검증 가능
❌ None   — 핵심 변인 없어 검증 불가

## 🧩 제안 모형
M1 — 모형명 🔴 High
- 경로: t_EE[AW_t] → ND_REC[BW_t] → ND_WM[BW_t]
- 분석 방법: DSEM_mediation
- 교차지연 가능: ✅ ...

## 🚫 제외 경로
기존 논문과 겹치거나 시간 역행 경로
```

## 내장 규칙

### 교차지연 가능 여부

| 경로 | 판단 |
|---|---|
| AW 변인 ↔ AW 변인 (동시점) | ✅ 가능 |
| AW 변인 → BW 변인 (lag-1) | ✅ 가능 |
| BW 변인 → AW 변인 | ❌ 시간 역행 |
| ND_REC ↔ ND_SBR | ❌ 불가 (암묵적 시간 선행) |

### 자동 제외 경로

- `부당대우 → EE → WM` (기존 투고 논문 주제)
- `부당대우 → WM` (기존 논문 직접 효과)

## 실행

```bash
# 가장 최근 지형 지도 사용 (권장)
python3 run.py strategy --latest

# 대화형 선택
python3 run.py strategy --pick

# 전체 지형 지도 종합
python3 run.py strategy --all
```

## 사용 시점

gap_synthesizer를 실행한 후 돌립니다.
논문이 많아져서 지형 지도가 풍부해질수록 제안 모형의 질도 높아집니다.

## 참고

- 어떤 직군의 논문에서 나온 갭이든 동등하게 평가합니다 (간호사 표본 아니어도 무관)
- 갭 커버리지 판단 기준: "우리 변인 구조로 검증 가능한가" (표본 동일 여부 아님)
- 제안 모형은 최대 4개로 제한 (비용 및 응답 안정성)
