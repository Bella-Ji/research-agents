# gap_synthesizer

여러 논문의 갭분석 결과를 종합하여 갭 지형 지도를 만듭니다.

## 역할

gap_explorer가 만든 `*_갭분석.md` 파일들을 모아서:
- 공통으로 반복되는 갭 패턴을 군집화
- 여러 논문에서 언급되지만 아직 검증되지 않은 경로를 정리
- 방법론적 갭(DSEM 미사용, lag 구조 미검증 등)을 별도 집계
- 이론별 등장 빈도를 정리

**모형을 제안하지 않습니다.** 갭의 지형을 그리는 역할입니다.
모형 제안은 gap_strategist가 담당합니다.

## 입력 / 출력

```
입력: *_갭분석.md 파일들 (gap_explorer 출력)
출력: gap_landscape_YYYYMMDD_HHMMSS.md (SYNTHESIS_DIR에 저장)
```

### 출력 구조

```
## 🗺️ 요약
전체 갭 지형을 2-3문장으로 요약

## 🔍 갭 군집
### 군집 1 — 군집명
- 갭 유형, 필요 모형, 관련 이론, 해당 논문
- 대표 갭 원문

## 🔗 미검증 경로
여러 논문에서 언급됐지만 아직 검증된 경로 없음

## 🔬 방법론적 갭
DSEM 미사용, lag 구조 미검증 등

## 📚 이론 빈도
이론별 등장 논문 수
```

## 실행

```bash
# 전체 갭분석 파일 종합
python3 run.py synth --all

# 특정 폴더만 선택
python3 run.py synth --folder "DSEM-empirical"

# 대화형 선택
python3 run.py synth --pick
```

## 사용 시점

gap_explorer로 논문을 어느 정도 쌓은 다음 돌립니다.
논문 5편 이상일 때 군집화가 의미 있게 나옵니다.
논문을 추가할 때마다 재실행하면 지형 지도가 갱신됩니다.

## 참고

- 표본이 다른 논문(간호사, 교사, 사무직 등)도 동등하게 종합합니다
- 파일당 최대 2,500자를 읽습니다 (토큰 비용 관리)
- 15편 초과 시 비용 경고 메시지가 나옵니다
