# Variable Dictionary (변인사전)

> 원본: Obsidian vault `변인사전.md` (2026-03-17). 에이전트용 요약본 — 척도 세부는 원본 참조.

## 1. Level 2 — 사전 설문 (개인 수준, 1회 측정)

### 인구통계·통제변인
| 변인 | 설명 | 값 |
|---|---|---|
| `age` | 나이 | 연속 |
| `sex` | 성별 | 1=여, 0=남 |
| `tenure_c` | 재직기간 | 햇수 |
| `C1` | 병원 종류 | 999=1차, 0=2차, 1=3차 이상 |
| `C4` (`C4_d1~d2`) | 근무 부서 | 1=병동, 2=특수파트, 3=외래 (더미: intercept=특수파트) |
| `respon` (`respon_d1~d3`) | 직책 | 1=일반, 2=책임, 3=관리, 4=전담 (intercept=일반) |
| `duty` (`duty_d1~d3`) | 근무 형태 | 1=2교대, 2=3교대, 3=고정, 4=나이트전담 (intercept=고정) |
| `duty_f` | 교대 여부 | 1=교대, 0=통상 |
| `night` | 월 나이트 횟수 | 연속 |

### 주요 심리 변인 (모두 Level 2 moderator 후보)
| 변인 | 설명 | 척도·문항 |
|---|---|---|
| `PSC` | 심리적 안전 풍토 | 5점, 12문항 |
| `PCEO` / `PCEO_5` | 심리적 계약 — 조직의 의무 | 5점, 8 / 5문항(2,6,7 제외) |
| `PCEF` / `PCEF_5` | 심리적 계약 — 조직의 이행 | 5점, 8 / 5문항(2,6,7 제외) |
| `p_EE` | 직무탈진 — 정서적 소진 | 5점 빈도, 8문항. 데일리 EE의 baseline 통제 / moderator |
| `p_PA` / `p_PA_d` | 자아성취감 / 저하(역코딩) | 5점 빈도, 7문항 |
| `p_DP` | 비인간화 | 5점 빈도, 5문항 |
| `p_JB` | 직무탈진 전체 (MBI 20문항) | EE 8 + PA저하 7 + DP 5 |
| `p_ABRC` / `p_ABDC` / `p_JC` | 잡크래프팅 자원/요구/전체 | 5점, 5/5/10문항 |
| `p_WM_PM` / `p_WM_MMTW` / `p_WM_GGM` / `p_WM` | 일 의미감 하위 3요인 + 전체 | 5점, 4/3/3/10문항. 데일리 WM baseline / moderator |
| `p_WL` | 업무부하 | 5점 빈도, 5문항 |

**사전 설문 moderator 후보**: p_EE, p_WM, PSC, PCEO, PCEF, p_JB, p_JC

## 2. Level 1 — AW 설문 (퇴근 후, 당일 경험)

### 근무 변인
| 변인 | 설명 |
|---|---|
| `TD_shift` (`TD_d1~d3`) | 오늘 근무 형태 (6=미근무 시 설문 종료) |
| `TD_f1` | 교대 여부 (1=교대, 0=통상) |
| `TD_f2` | 밤 근무 여부 (1=나이트/나이트전담) |
| `NXT_shift` (`NXT_d1~d4`) | 내일 근무 형태 (BW의 `JB_shift`와 대응) |
| `d_duty` (`duty_d1~d3`) | 근무 형태 (intercept=고정) |

### 데일리 변인
| 변인 | 설명 | 비고 |
|---|---|---|
| `t_MPFs` / `t_MPFm` | 환자·보호자 부당대우 횟수 (합/평균, 4문항) | 이분 버전: `t_MPF_ds/dm` (경험 유무) |
| `t_MBSs` / `t_MBSm` | 상사 부당대우 횟수 (합/평균, 3문항) | 이분: `t_MBS_ds/dm` |
| `t_MBCs` / `t_MBCm` | 동료 부당대우 횟수 (합/평균, 3문항) | 이분: `t_MBC_ds/dm` |
| `t_MSTs` / `t_MSTm` | 전체 부당대우 횟수 (합/평균, 10문항) | 이분: `t_MST_ds/dm` |
| `t_EE` | 정서적 소진 (당일) | 5점, 3문항 평균 |
| `t_ABRC` / `t_ABDC` / `t_JC` | 잡크래프팅 자원/요구/전체 (당일) | 5점, 2/2/4문항 평균 |

> 부당대우 빈도가 영과잉(zero-inflated)이면 이분(`_ds/_dm`) 버전이 대안.

## 3. Level 1 — BW 설문 (다음 날 출근 전)

| 변인 | 설명 | 실제 측정 시점 |
|---|---|---|
| `jb_SQ` | 전날 수면 시간 (hour) | 전날 밤 |
| `ND_REC` | 회복경험 (5점, 4문항) | **전날 퇴근 후~취침 회고 → 실질적으로 AW와 동시점** |
| `ND_SBR` | 회복상태 (5점, 2문항) | 측정 당시 (출근 전 아침 현재) |
| `ND_WM` | 일의 의미감 (5점, 3문항) | 측정 당시 (출근 전 아침) |
| `JB_shift` | 직전 날 근무 형태 | AW의 `TD_shift`와 동일해야 함 |

- **AW 모형**: TD_shift(또는 TD_f1/TD_f2), 인구통계
- **BW 모형**: JB_shift, jb_SQ(수면시간 — 회복 관련 핵심 통제), d_duty
- **Level 2**: age, sex, tenure_c, C1, C4, respon, duty
