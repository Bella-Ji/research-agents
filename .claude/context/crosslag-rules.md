# Cross-Lag Rules (교차지연 판단 규칙)

> 원본: 변인사전 §6 + gap_strategist 내장 규칙. 모형 제안 시 반드시 이 규칙으로 경로 타당성을 판단한다.

## 핵심 원리

1. **동시점 변인끼리는 양방향 교차지연(cross-lagged) 가능.**
2. **설계상 이미 시간적 선행이 확립된 경로는 순방향 lag-1 경로는 가능하지만, 양방향 교차지연은 불가** (Mplus에서 재라그 불가).
3. **같은 관찰쌍의 시간 역행 경로(BW_t → AW_t)는 항상 불가.** 다음 관찰쌍으로 이어지는 `BW_t → AW_{t+1}`는 시간 역행이 아니므로, 연구 질문과 실제 시간 배열을 확인하여 별도로 판단한다.

## 변인별 시간 위치

| 변인 | 물리적 측정 | 실질적 시점 |
|---|---|---|
| 부당대우, t_EE, t_JC, t_ABRC, t_ABDC | AW (퇴근 후) | 당일 근무 (day t) |
| ND_REC | BW (다음 날 아침) | **AW(day t) 퇴근 후~취침 전 회복경험을 회고 측정** |
| jb_SQ | BW | 전날 밤 수면 |
| ND_SBR | BW | 측정 당시 아침 (day t+1) |
| ND_WM | BW | 측정 당시 아침 (day t+1) |

## 판단 표

| 경로 | 판단 | 이유 |
|---|---|---|
| AW 변인 ↔ AW 변인 (부당대우, t_EE, t_JC, t_ABRC, t_ABDC) | ✅ 양방향 교차지연 가능 | 동시점 |
| AW 변인 → ND_REC (예: t_EE_t → ND_REC_{t+1}) | ⚠️ 순방향만 가능 | AW 퇴근 시점 이후의 회복경험을 다음 날 BW에서 회고 측정 |
| ND_SBR ↔ ND_WM | ✅ 양방향 교차지연 가능 | 둘 다 아침 측정, 동시점 |
| AW 변인 → BW 변인 (예: t_EE → ND_WM, t_EE → ND_SBR) | ⚠️ **순방향 lag-1 경로만 가능** | 24시간 시간 선행이 설계상 확립 → 양방향 교차지연은 불가 |
| 같은 관찰쌍의 BW 변인 → AW 변인 (예: ND_WM_t → t_EE_t) | ❌ 불가 | 같은 관찰쌍 안에서 시간 역행 |
| 다음 관찰쌍의 BW 변인 → AW 변인 (예: ND_WM_t → t_EE_{t+1}) | ⚠️ 별도 판단 | 다음 관찰쌍으로 이어지는 시간 순방향이며, 위의 시간 역행 금지에 해당하지 않음 |
| ND_REC ↔ ND_SBR | ❌ 교차지연 불가 | 둘 다 BW 설문이지만 REC=전날 밤, SBR=현재 아침 → 암묵적 시간 선행 존재 |
| jb_SQ | ❌ 교차지연 불가 | 단방향 통제변인으로만 사용 |

### 대표 사례 (변인사전 §6 표 원문 기준)

| 변인 쌍 | 측정 간격 | 처리 |
|---|---|---|
| AW 부당대우 → AW t_EE | 동시 | contemporaneous 경로, 교차지연 가능 |
| AW t_EE → BW ND_WM | 24시간 lag-1 | clean lag-1 순방향 ✅ / 양방향 교차지연 ❌ |
| AW t_EE → BW ND_REC | AW → 다음 날 BW | 퇴근 후 회복경험을 다음 날 회고 측정하는 순방향 경로 ✅ |
| AW t_EE ↔ BW ND_SBR | 24시간 lag-1 | 순방향 경로 가능 / **양방향 교차지연 불가** (2026-06-12 연구자 확인) |
| BW ND_REC ↔ BW ND_SBR | 동시 설문 | 교차지연 금지 (REC는 전날 밤 회복경험, SBR은 현재 아침 상태) |

## 자동 제외 경로 (기존 투고 논문 중복)

- `부당대우 → t_EE → ND_WM` (매개 경로 전체)
- `부당대우 → ND_WM` (직접 효과)
- `t_EE → ND_WM` (단독 경로 — 기존 모형의 일부)

제외 사유: 이미 논문화된 주제이며, 동일 경로를 DSEM으로 재검증하는 것도 차별성 부족.

## 표본 원칙

- 갭 지형 지도에 포함된 논문들의 표본(간호사, 교사, 사무직, 제조업 등)이 연구자 데이터(한국 간호사)와 달라도 상관없다.
- 직업건강심리학 갭은 특정 직군에 국한되지 않고 조직 구성원 일반에 적용되는 이론적 갭이다.
- 표본이 다르다는 이유로 갭의 적용 가능성을 낮게 평가하지 말 것.
- 갭 커버리지 판단 기준은 "우리 데이터의 변인 구조로 검증 가능한가"이며, "같은 직군에서 나온 갭인가"가 아니다.

## 확장 모형 아이디어 (변인사전 §6)

- **L2 조절**: `p_EE`가 부당대우 → t_EE 경로 조절
- **2단계 매개**: t_EE → ND_REC/ND_SBR → ND_WM
- **within-person 조절**: `t_JC`가 부당대우-EE 경로 완충
- **L2 투입**: `t_EE_m`, `ND_WM_m` 등 person-mean 집계 변인으로 개인 간 차이 설명
