논문 초안을 검토하고 지적·근거·수정안 3요소가 갖춰진 보고서를 생성한다.
초안 원본은 수정하지 않는다.

## 인자

`$ARGUMENTS`

- 첫 번째 인자: 초안 MD 파일 절대경로
- 두 번째 인자 (선택): 검토할 섹션명 (예: "Discussion", "Theoretical Implications")
  생략 시 파일 전체 검토

인자가 없으면 사용자에게 파일 경로를 확인한다.

## 실행

**draft-reviewer 서브에이전트를 호출한다** (`subagent_type: draft-reviewer`).
프롬프트에 초안 파일 경로와 섹션명(있으면)을 전달한다.

## 완료 보고

에이전트가 생성한 보고서 파일 경로와 축별 지적 수 요약을 출력한다.
